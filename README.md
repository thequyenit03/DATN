# ECOMERCE
Đây là dự án thương mại điện tử sử dụng ANGULAR 19 và ASP.NET 9.0

## Cài đặt
1. Clone dự án: 
    Sử dụng bash hoặc bạn có thể dowload trực tiếp từ github và giải nén
2. Giải nén
    Sau khi tải xong bạn giải nén file ra.
3. Cài đặt csdl
    Bạn mở file script.sql và chạy tạo CSDL
4. Kết nối backend với CSDL
    Mở Service và tìm tới appsetting.json và thay đổi đường dẫn của bạn
    "ConnectionStrings": {//Đường dẫn của bạn }
5. Chạy phía Backend, và frontend sử dụng angular ng start
lưu ý: chỉ khi frontend kết nối được với backend thì mới có thể hiển thị giao diện
